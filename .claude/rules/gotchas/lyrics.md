# Gotchas: Lyrics

- **A plain lyric sheet's stamps are all `time_ms == 0`**: drive it through `drift_center` (playback progress × `n - 1`, plus the wheel's `drift_offset`, clamped), and never search its stamps by time: every zero stamp passes a `partition_point`, which would name the LAST line from the first tick and highlight it for the whole track. `LrcDocument::active_line_at` returns `None` for a plain doc, and the apply path and the tick (the only writers of `active_index`) both go through it, so `active_index` stays `None` for a plain sheet's whole life. Write the wheel offset already clamped, via `drift_offset_for` (the exact inverse of `drift_center`), so nothing banks hidden overshoot and a notch lands where it asked even in the final second, where the tick's whole-second duration puts progress above 1.0.
- **Lyrics overlay identity**: the lyrics + blurred-cover layer must gate on the **transport** (`playing || paused`), never on `current_song_id` / `is_queue()` — both survive `stop()` and are seeded from the restored queue at login, so gating on them scrims a bare cover with no audio. The backdrop must key on the **shown/resolved cover handle**, not the playing track: during the cold-art window the panel falls back to the centered row's cover, so rendering the playing track's lyrics over a *different* album is wrong.
- **The lyric clock is not the position**: the word-level highlight reads `LyricsState::clock_ms`, which the frame tick runs on from the last position tick (`lyric_clock_ms`, `src/state/lyrics.rs`) and which only ever moves forward within a track; a tick more than `LYRIC_CLOCK_SEEK_BACK_MS` (300 ms) behind it is a seek and snaps it back. It is deliberately NOT gated on the seek epoch (a stale pre-seek tick costs one tick, then the next one snaps), the position handler re-runs it right after anchoring so the line it names never draws against the old reading, and `clear()` / `promote_next()` zero it, because the frame tick would otherwise carry the previous track's reading over a new sheet until a tick fell far enough behind. Every Lyrics mode writer (the player-bar toggle in Off and On, the Settings row, a `config.toml` reload, the last two through `handle_player_settings_loaded`) goes through `lyrics_mode_changed`, whose Off edge calls `clear()`: with lyrics off a song change clears nothing, so a sheet kept through an off-period came back over the next song with its clock.
- **Navidrome invents cue ends**: its normaliser gives a cue with no `end` one whenever the line has a fallback (the next cue's start; for a line's last cue the line's own `end`, a TTML `<p end>`, else the NEXT line's start), and clears every end of the sheet's last line when it has none; a bare space between two word stamps arrives as a cue of its own. So `LrcDocument::from_structured` strips a last word's end that EQUALS the next line's start (that fill would hold the word lit through the whole gap; a source end of exactly that value is indistinguishable and takes the same pace fallback). Both word sources then end in `fold_word_markers` (`types/lyrics.rs`): every word trimmed, a textless cue or blank `<mm:ss.xx>` marker folded into the previous word's end, so a store file and the same sidecar served by Navidrome give equal words (pinned by `a_sidecar_and_the_server_cues_for_it_give_the_same_words`); a new word source goes through it too. `LrcLine::word_window` then honours every remaining end, cut at the next line's start, so a held note that runs into the next line sweeps until it begins. Navidrome reads sidecars at REQUEST time, so a `.elrc` beside the audio needs no rescan and never shows in the database.
- **Two lyrics gates, not one** (`LyricsMode`: Off / On / Auto): `lyrics_mode.is_active()` (On or Auto) gates the work, meaning lookups, prefetch, the song-change clear/promote, the tick's line cursor, the lyric clock and the blur job, so a sheet Auto keeps hidden stays current for a re-show. `Nokkvi::lyrics_layer_wanted()` gates what is drawn: the cover layer (`queue_lyrics_panel_data`, so Theater too), the frosted cover, the paused cover lock and the player-bar button's lit state. In Auto it is `LyricsState::auto_shows` for the current song: Toggle Lyrics' per-song `auto_override`, else whether the song's matched sheet has lines, so an unresolved song stays on the plain cover (no empty-overlay flash). The override drops at every song change (`clear()` / `promote_next()`) and mode change. At a song change `current_song_id` already names the NEXT song, so the outgoing sheet is judged by its own song (`lyrics_sheet_on_screen`) before it parks to dissolve, and the dissolve is dropped when the next song starts uncovered, or it would surface mid-fade once that song's lyrics land.
